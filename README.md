# Todo Application

A simple and efficient Todo application designed to help users manage daily tasks.
This project demonstrates strong frontend fundamentals and clean UI-focused development.

---

## Technologies Used

* **HTML5** – Structuring the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Application logic and interactivity

---

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Task persistence using browser local storage
* Responsive design for mobile and desktop devices

---

## Development Process

1. Designed the basic layout using HTML
2. Styled the interface with CSS for clarity and responsiveness
3. Implemented core functionality using JavaScript:

   * Adding tasks
   * Completing tasks
   * Deleting tasks
4. Integrated local storage to retain tasks after page refresh
5. Tested the application for usability and edge cases
